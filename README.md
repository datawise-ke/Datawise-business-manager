
# DataWise Business Manager

**Turning Business Data Into Better Decisions.**

DataWise Business Manager is a business analytics and inventory management application designed to help small businesses manage their daily operations.

## Planned Features
- Record daily sales
- Track business expenses
- Manage stock and inventory
- Calculate profit
- Generate business reports
- View sales dashboards

## Technologies
- Python
- Pandas
- Streamlit
- PostgreSQL

## Project Status
Currently in development.
